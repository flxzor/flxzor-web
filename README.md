# Personal Portfolio & Blog

A personal portfolio and blog website where I showcase my projects, share what I learn, and document my journey as a Software Engineering student.

## 🛠️ Tech Stack

* Next.js
* React
* Tailwind CSS
* Hygraph
* GraphQL
* GSAP
* Vercel

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
cd <your-project-folder>
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```env
NEXT_HYGRAPH_ENDPOINT=your_hygraph_endpoint
```

Run the development server:

```bash
npm run dev
```

Then open `http://localhost:3000` in your browser.
